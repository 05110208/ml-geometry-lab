# ML Geometry Lab

### See the mathematics behind machine learning.

ML Geometry Lab is an open-source project for understanding machine learning through mathematics, geometry, visualization, and experiments.

Instead of treating machine learning algorithms as black-box APIs, this project makes the underlying mathematics visible and experimentally understandable.

> Every equation should become an experiment.

---

## 🧭 Core Idea

The project follows:

**Mathematics → Geometry → Algorithm → Code → Visualization → Experiment**

The goal is not simply to implement an algorithm, but to understand why it works.

---

## 🔬 Current Focus

The first version focuses on:

- Linear Regression
- Least Squares
- Loss Functions
- Gradient Descent
- Gradient Descent Visualization

Future topics will include:

- Perceptron
- Logistic Regression
- Decision Trees
- Overfitting
- Regularization
- PCA
- Neural Networks
